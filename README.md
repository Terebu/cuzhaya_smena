# Бесконечное лето: Чужая смена

Играбельная версия: пролог и два завершённых дня. Третий день пока не реализован.

Установка: поместите папку `chuzaya_smena` в `Everlasting Summer/game/mods/`. Запустите игру и выберите «Чужая смена» в списке модификаций.

Создано с помощью ИИ. Музыка: Purrple Cat · FreeLofi (https://freelofi.com/), пользовательские композиции и оригинальная музыка «Бесконечного лета».

Лицензия используемого шрифта находится в `fonts/NotoSansCJKjp-OFL.txt`.
