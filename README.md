# Бесконечное лето: Чужая смена

Играбельный пролог «Четыреста десятый» для установленной Everlasting Summer 1.6 / Ren’Py 7.4.11.2266. Семь сцен заканчиваются на вывеске «СОВЁНОК»; продолжение не добавлено.

## Запуск

1. Запустите Everlasting Summer через Steam или обычный EXE игры.
2. В главном меню нажмите «Инструменты» → «Настройки».
3. Прокрутите настройки вниз и откройте «Модификации».
4. Выберите «Чужая смена».

Щелчок/пробел — следующая реплика. Штатные кнопки диалогового окна открывают сохранение, загрузку и историю; Escape открывает меню. Пропуск и автоматическое чтение используют штатные настройки игры.

## Структура

- `scriot.rpy` — регистрация и последовательный вызов сцен; исходное имя точки входа сохранено.
- `characters.rpy` — Лена Соколова, Дарья, повествование, мысли; все ID с префиксом `cs_`.
- `resources.rpy` — оригинальные ресурсы, пользовательские спрайты, адаптированные фоны; размеры спрайтов задаются кодом.
- `transforms.rpy` — посадка персонажа и движение камеры.
- `phone.rpy` — немодальный интерфейс телефона.
- `days/prologue/01_ordinary.rpy` … `07_summer.rpy` — семь самостоятельных сцен пролога.
- `days/day01/00_day01.rpy` — порядок эпизодов и точка продолжения; `01_bus.rpy`, `02_recognition.rpy`, `03_reality.rpy`, `04_reflection.rpy`, `05_home.rpy`, `06_slavya.rpy` — шесть сцен постановочной редакции. `resources.rpy` рядом — музыка и расположение Даши при встрече со Славей. День не завершается автоматически.
- `source/day01_staged.md` — актуальная постановочная редакция; `tools/build_day01_staged.py` — её генератор. `source/day01_part01.md` и `tools/build_day01.py` сохранены как предыдущая версия; старый генератор поверх текущих сцен запускать нельзя.
- `source/` — неизменённые приложенные сценарий и техническое задание.
- `tools/build_slice.py` — первоначальный перенос исходного текста и генерация масок (Python 3 + Pillow; не требуется игроку). Не запускайте поверх текущих сцен: последующие ручные правки постановки и пользовательских фонов в этот первоначальный генератор не перенесены.
- `tools/verify_slice.py` — независимая сверка текста и ресурсов.
- `qa/` — opt-in тест движка, результаты проверок, скриншоты и справочные изображения.

Оригинальные изображения Даши не изменены. Актуальная система полных спрайтов и дистанций описана ниже; старый dasha_sheet.png не подключён.
Списки ресурсов и ограничения — в `ASSET_REPORT.md`, фактические результаты — в `QA_REPORT.md`.

У ворот включаются штатные day_time() и persistent.sprite_time = day: диалоговое окно получает зелёную дневную тему.
Вторая часть первого дня: days/day01/07_uninvited.rpy, 08_camp_walk.rpy, 09_counsellor.rpy. Следующий материал нужно вставлять перед cs_day01_next_part. Старый ярлык cs_check_day01_pending сохранён для загрузок конца первой части; на старом экране доступна кнопка Продолжить.

Полные PNG Дарьи регистрирует dasha_sprites.rpy. Размер и прозрачные границы берутся из sp/dasha_metadata.json; после замены исходников обновите их командой python tools/build_dasha_metadata.py. Идентификаторы: cs_dasha_winter N normal/far/close, cs_dasha_pioneer N normal/far/close; прежние cs_dasha neutral/smile/interested/sleep и cs_dasha_full N также действуют. Нормальная высота видимой фигуры 1420, far 0.7, close 1.28; исходники не обрезаются и не изменяются.

## Обновлённые эмоции и присутствие Дарьи

Текущий набор sp/Dasha sprites/new заново переименован по фактическим позам: neutral, serious, surprised, explaining, worried, smile, thinking, wave, arms_crossed, shrug. Файлы называются darya_pioneer_<поза>.png. Метаданные и SHA256 обновлены; PNG не обрезались и не перекодировались. Имена sad/shy оставлены как совместимые семантические aliases на worried/surprised, старые числовые объявления также доступны.

В прологе и всех сценах дня 1 присутствие Дарьи теперь связано с её обменами репликами с Леной. В самостоятельных размышлениях, при обращении к Ольге, Славе или Семёну и после окончания обмена спрайт скрывается. Короткие действия внутри разговора могут сохранять спрайт, чтобы не создавать мигание. Пионерские реакции меняются по смыслу: возражение — arms_crossed, вопрос/гипотеза — thinking, беспокойство — worried, лёгкая ирония — smile/shrug. Зимние сцены используют соответствующие существующие рисунки.

Постановку в отдельных rpy поддерживает tools/stage_darya_dialogue.py. После запуска любого генератора сцен запустите python tools/stage_darya_dialogue.py. Это офлайн-инструмент: в самой игре используются явные show/hide, текст и музыка не анализируются на лету. Повторный запуск не меняет результат; контрольные точки и сюжетный текст сохраняются. Манифест проверки: qa/darya_staging_manifest.json.


Уточнение постановки Дарьи: спрайт сохраняется на протяжении разговора, включая короткие описания действий и паузы. Скрытие происходит при переключении на другого собеседника, длинном внутреннем монологе или завершении сцены. Появление, смена эмоции и скрытие используют Dissolve(0.5). Проверка текста: PASS, 383 блока пролога и 1364 блока первого дня без изменений.
