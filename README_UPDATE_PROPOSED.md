# Бесконечное лето: Чужая смена

Мод для «Бесконечного лета» (Ren'Py). Лена Соколова и Дарья Еретикова засыпают в автобусе 410 и просыпаются в «Совёнке».

## Что доступно

Пролог и три дня. Четвёртый день пока не написан: после третьего дня игра останавливается на заставке «Конец третьего дня».

Через Steam Workshop (подписка на мод) или вручную: папку мода поместить в `game/mods/` игры.
