# Credentials

No access tokens or private keys are required by this mod.
Archived stock-site HTML contains REDACTED placeholders instead of session tokens.
Original pages were encrypted outside this repository using Windows DPAPI CurrentUser.
The encryption key is managed by Windows and is not shipped or committed.
RPYC files are compiled scripts, not a secure place for credentials.
Never commit live credentials, .env files, private keys, or the private encrypted vault.
