# CG для «Чужой смены»: шестой день

12 отдельных PNG, 1920×1080, строго 16:9. Основные сцены, четыре дополнительные CG и переход «Пропавшая минута» из пятого дня.

## Состав

- `cg_day06_blank_pages_morning.png` — Утро без записей
- `cg_day06_semen_farewell_day.png` — Прощание с Семёном
- `cg_day06_archive_comparison_day.png` — Сверка документов в архиве
- `cg_day06_pier_evening.png` — Разговор на пристани
- `cg_day06_fifth_place_intact.png` — Пятое место: целый хлеб
- `cg_day06_fifth_place_changed.png` — Пятое место: хлеб изменился
- `cg_day06_separate_beds_night.png` — Ночной разговор
- `cg_day06_drawing_by_library.png` — Рисование у библиотеки
- `cg_day06_semen_bus_wave.png` — Семён машет из окна
- `cg_day06_cards_four.png` — Карты на четверых
- `cg_day06_fifth_place_tray.png` — Вымытый пятый прибор
- `cg_day05_missing_minute.png` — Пропавшая минута: переход из пятого дня

## Рекомендуемый порядок показа

Пропавшая минута (завершение дня 5) → утро → рисование у библиотеки → объятие с Семёном → взмах из окна → архив → пристань → карты → пятый прибор с целым хлебом → пятый прибор с изменившимся хлебом → поднос → ночной разговор.

Варианты пятого прибора показывать в одном ракурсе, без движения камеры между состояниями. Второе состояние получено редактированием первого. Это не обещание побитового совпадения остальных пикселей: генеративная правка слегка меняет мелкие текстуры.

## Формат

Генератор вернул исходники 1672×941. В этом пакете выполнен экспорт Full HD с интерполяцией Lanczos и минимальным приведением кадра к точным 16:9. Это увеличение размера существующего изображения, не дополнительная генерация деталей.

## Преемственность

Лена Соколова — длинные фиолетовые волосы, зелёные глаза; Тихонова в сцене рисования — отдельная девушка с короткими хвостиками. Даша — рыжие волосы до плеч, зелёные глаза. Соколова без повязки. Дневной автобус — обычный лагерный. Ночью отдельные кровати, пятая посуда после уборки без еды.

## Дополнительные файлы

`prompts.md` — фактически использованные промпты. `scene_plan_and_references.md` — разбор сцен и ссылки на материалы мода и оригинального БЛ. `manifest.json` — имена, размеры и контрольные суммы PNG.

Графика создана встроенной генерацией изображений с референсами. В репозиторий изменения не внесены. При интеграции проверьте композиции с реальным текстбоксом: часть предметов и рук находится в нижней части CG.
