## Реализация развилки в Ren'Py

Codex должен создать один постоянный счётчик дружбы, который сохраняется вместе с прохождением, а не через `persistent` — иначе очки могут переноситься между новыми играми.

```

# Объявить один раз вместе с переменными мода.
default cs_friend_un = 0
default cs_met_un = False

# Пример структуры переходов.
# Названия label согласовать с существующим проектом.

label cs_d1_p9_choice:

    menu:
        "Остановиться и познакомиться":
            $ cs_friend_un += 1
            $ cs_met_un = True
            jump cs_d1_p9_talk

        "Извиниться и пройти дальше":
            jump cs_d1_p9_pass

label cs_d1_p9_talk:

    # Сюда Codex вставляет сцену 48А.
    # Дополнительные очки не начислять.
    jump cs_d1_p9_join

label cs_d1_p9_pass:

    # Сюда Codex вставляет сцену 48Б.
    jump cs_d1_p9_join

label cs_d1_p9_join:

    # Общие сцены 49–51.
    # Далее jump к следующей части первого дня.
    pass

```

`cs_met_un` нужен отдельно от очков, чтобы в следующих сценах игра понимала, знакомы ли героини лично. Если игрок прошёл мимо, при следующей встрече Лена Тихонова не должна внезапно обращаться к Соколовой по имени.

# Codex — Chuzhaya Smena, день 1, часть 9

**Основной принцип:** сюжет линейный, отношения с персонажами влияют на дополнительные диалоги и дружеские эпилоги, но не меняют основную последовательность событий.

### Развилка

В сцене 47 показать два выбора игрока:

1. «Остановиться и познакомиться» — `cs_friend_un += 1`, `cs_met_un = True`, выполнить сцену 48А.
2. «Извиниться и пройти дальше» — 0 очков, выполнить сцену 48Б.

После обеих ветвей перейти к общей сцене 49. Никакого повторения выбора или двойного начисления.

В сцене 48А героини знакомятся, разговаривают о рисовании, а Семён ненадолго появляется и замечает совпадение имён. В сцене 48Б Лена Соколова просто проходит мимо. Нельзя показывать пропущенные диалоги игроку, выбравшему второй вариант.

- Дарья — обычная девушка из 2026 года, человек, романтический интерес Лены Соколовой.

- Лена Соколова и Лена Тихонова могут стать подругами, но между ними нет романтической линии.
