## Реализация развилки в Ren'Py

Эта часть добавляет второй независимый счётчик дружбы. После предыдущей развилки с Леной Тихоновой игрок может получить:

| Персонаж      | Возможный результат к концу этой части |
| ------------- | -------------------------------------- |
| Лена Тихонова | 0 или 1 очко                           |
| Женя          | 0 или 1 очко                           |

Причём знакомства не зависят друг от друга. Можно подружиться с обеими, с одной или пока ни с кем.

```

# Объявить один раз в файле переменных мода.
default cs_friend_mz = 0
default cs_met_mz = False

label cs_d1_p10_friendship_choice:

    # Знакомство с Женей произошло в общей сцене.
    $ cs_met_mz = True

    menu:
        "Предложить Жене помощь с книгами":
            $ cs_friend_mz += 1
            jump cs_d1_p10_help_mz

        "Не отвлекать Женю от работы":
            jump cs_d1_p10_no_help_mz

label cs_d1_p10_help_mz:

    # Сцена 55А. Очко уже начислено.
    # Здесь вставить дружеский диалог.
    jump cs_d1_p10_join

label cs_d1_p10_no_help_mz:

    # Сцена 55Б. Никаких дополнительных очков.
    # Здесь вставить нейтральный диалог.
    jump cs_d1_p10_join

label cs_d1_p10_join:

    # Общие сцены 56–58.
    # Дальше переход к следующей части.
    pass

```

### Почему эта развилка работает

Я изменил мотивацию Лены. В исходном черновике она шла в библиотеку преимущественно ради того, чтобы подразнить Женю. Это было забавно, но плохо подходило для начала дружеской линии. Теперь у неё есть реальная цель — проверить исторические сведения — и естественная возможность проявить внимание к человеку, с которым она хочет сблизиться.

При этом Женя не превращается в дружелюбную собеседницу после одного хорошего поступка. Одно очко — лишь начало доверия. Её скепсис по поводу путешествия во времени остаётся одинаковым при обоих вариантах.

И я сохранил важную сюжетную интригу: Лена снова случайно проговаривается о знакомой игре. Но теперь она не заявляет Жене, что та ненастоящая. Это делает предстоящий разговор гораздо серьёзнее и оставляет Жене право самой решать, верить ли рассказу новенькой.

Следующую, одиннадцатую часть первого дня логично посвятить короткому объяснению в библиотеке, последствиям очередного откровения Лены и возвращению девушек в домик перед отбоем.
