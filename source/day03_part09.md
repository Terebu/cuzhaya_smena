## День 3 — сцена на площади и совместное рисование

Интегрируй новую редакцию сцен 137–145 в существующий сценарий третьего дня.

### 1. Стыковка с предыдущими частями

В предыдущей версии уже есть короткая встреча с Семёном после библиотеки.

**Заменить её новой расширенной сценой, а не создавать вторую встречу.**

Порядок событий:

1. Лена заканчивает чтение у Жени.
2. Встречает Дарью после занятий с Мику.
3. Девушки проходят через площадь.
4. Разговаривают с Семёном.
5. Игрок делает выбор дружбы.
6. При накопленном доверии Семён даёт полезную подсказку.
7. Девушки возвращаются в домик.
8. Книга и плакат занимают свои места.
9. При открытом событии проходит совместное рисование с Леной Тихоновой.
10. Сюжет переходит к общей вечерней последовательности.

Не повторять встречу с Семёном из старой сцены 137.

### 2. Дружба с Семёном

Проверить существующую переменную `cs_friend_se` и все предыдущие начисления.

Перед новой развилкой сохранить прежнее значение:

```
$ cs_se_friend_before_square_day3 = cs_friend_se
```

Для реакций, которые должны зависеть именно от ранее накопленной дружбы, использовать `cs_se_friend_before_square_day3`.

В сцене 140 реализовать один выбор.

**Остаться и поговорить с Семёном:**

```
$ cs_friend_se += 1
$ cs_se_day3_personal_talk = True
```

**Дать Семёну отдохнуть:**

- Очки не изменять.
- Никаких штрафов.
- Семён остаётся в хорошем расположении духа.

Не создавать романтический маршрут Семёна.

Не делать дружбу обязательной для прохождения основной истории.

### 3. Реальные последствия дружбы

При предыдущем значении `cs_friend_se >= 2` Семён открытее обсуждает собственные сомнения о пребывании в лагере.

Не делать из этого мистическое откровение.

Не приписывать ему знания о природе лагеря, которых нет в текущем сценарии.

Если также установлен:

`cs_un_sketch_time_agreed_day3 == True`

Семён может предложить удобное место для рисования.

Установить:

```
$ cs_se_sketch_spot_day3 = True
```

Этот флаг должен повлиять на следующую художественную сцену: при его наличии девушки используют подсказанную Семёном скамейку.

Если дружба ниже порога, место выбирают самостоятельно.

### 4. Лена Тихонова

Проверять:

- `cs_friend_un`
- `cs_un_sketch_invite_day3`
- `cs_un_sketch_time_agreed_day3`

Если встреча ранее назначена, она должна состояться.

При `cs_friend_un >= 3` Тихонова добровольно показывает Лене один из личных рисунков.

После показа установить:

```
$ cs_un_private_drawing_shown_day3 = True
```

После завершения совместного рисования:

```
$ cs_un_sketch_completed_day3 = True
```

Не начислять очки за показ рисунка автоматически.

Это награда за накопленное доверие.

Если встреча не была назначена, использовать самостоятельную сцену рисования без Тихоновой.

Не допускать одновременного воспроизведения обеих ветвей.

### 5. Сохранение других дружеских событий

При переходе к вечеру не терять флаги:

- `cs_mi_followup_invitation_day3`
- `cs_dv_followup_invitation_day3`
- `cs_mz_open_library_invitation_day3`
- `cs_sl_poster_collected_day3`

Приглашения Мику и Алисы независимы.

Если активны оба, сохранять оба до соответствующих встреч.

Не обнулять показатели дружбы при переходе между частями.

### 6. Предметы

После возвращения в домик:

- Книга Гончарова находится у Лены.
- Если концертный плакат был получен, Дарья оставляет папку на столе.
- Повязка остаётся на локте Лены.
- Запасные перевязочные материалы сохраняются, если Виола выдала их раньше.

Не показывать один предмет одновременно в нескольких местах.

### 7. Характеры

**Лена Соколова:** саркастична, уже привыкла к лагерю, но постепенно учится уважать границы других. С Семёном шутит свободно, без систематического унижения.

**Дарья:** обычная девушка из Москвы 2026 года, увлекается музыкой и умеет играть на пианино. Не создавать намёков на необычное происхождение.

**Семён:** способен отвечать на шутки и проявлять инициативу в разговоре. Дружеское сближение не превращать в романтику.

**Лена Тихонова:** сдержанная художница. При высоком доверии показывает более личную работу, но не становится резко общительной.

### 8. Спрайты и фоны

Проверить фактические зарегистрированные фоны, музыкальные композиции, персонажные теги и эмоции.

- На площади — Семён и Дарья.
- После ухода от лавочки — Дарья.
- В домике — Дарья.
- Во время совместного рисования — Лена Тихонова, тег `un`.
- Лена Соколова — POV.

Не скрывать персонажей из-за отсутствия сидячих поз.

При переходе к сцене рисования использовать существующий дневной фон. Не создавать отсутствующий BG для скамейки.

### 9. Новые флаги

Если аналогов ещё нет, добавить:

```
default cs_se_day3_personal_talk = False
default cs_se_sketch_spot_day3 = False
default cs_un_private_drawing_shown_day3 = False
default cs_un_sketch_completed_day3 = False
```

Не создавать повторные объявления существующих флагов.

### 10. Проверка

Проверить обе ветви выбора с Семёном, старые значения дружбы от нуля до трёх, оба варианта художественной сцены, сохранение книги и плаката, независимость приглашений Мику и Алисы, а также переход к вечерней последовательности.

Провести Ren'Py Lint при наличии SDK.

В отчёте указать фактически изменённые файлы, выполненные проверки и оставшиеся ошибки. Не заявлять о проверках, которые не запускались.

Разветвление через `menu`, а затем возвращение к общему сюжету с сохранёнными переменными и флагами соответствует официальному подходу Ren'Py.&#x20;

### Что теперь изменилось в третьем дне

Самое важное — Семён перестаёт существовать исключительно как объект шуток Лены. Он становится её приятелем, которому она может доверять и который сам способен ей помочь.

При этом срабатывают уже накопленные очки с Тихоновой: игрок, развивавший дружбу, получает полноценное совместное рисование и более личный разговор, а не очередное обещание когда-нибудь встретиться.

И третий день по-прежнему обходится без новых мистических происшествий. Здесь развиваются отношения, чтобы начиная с четвёртого дня игроку действительно было за кого переживать.
