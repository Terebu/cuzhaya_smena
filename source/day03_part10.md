## Техническое задание для Codex

### 1. Стыковка с предыдущей частью

Новая часть состоит из сцен 146–153.

Она начинается после завершения одной из художественных ветвей:

- Сцена 144 — совместное рисование с Леной Тихоновой.
- Сцена 145 — самостоятельное рисование.

Обе ветви должны возвращаться к общей сцене 146.

Не проигрывать их последовательно. Не дублировать возвращение в домик.

К этому моменту книга Гончарова уже находится в домике после посещения библиотеки. Лена берёт её для продолжения чтения, а не получает повторно.

Дарья вернулась после своих занятий с Мику.

### 2. Время чтения

Главная хронологическая правка касается продолжительности чтения.

Если `cs_un_sketch_completed_day3 == True`, Лена возвращается после художественной встречи. До ужина остаётся достаточно времени только на непродолжительное чтение и разговор.

Если `False`, Лена может провести за книгой значительно больше времени.

Нельзя одновременно показывать двухчасовое чтение после долгой вечерней встречи с Тихоновой.

Горн к ужину звучит в сцене 152, независимо от маршрута. Только один раз.

### 3. Счётчик дружбы с Дарьей

Перед реализацией найди в проекте существующий показатель дружбы или доверия к Дарье.

Не создавай второй счётчик, если подходящий уже используется.

Если системы для Дарьи ещё нет, можно добавить:

```
default cs_friend_da = 0
```

В сцене 148 реализовать меню:

```
menu:
    "Отложить книгу и расспросить Дашу о музыке":
        $ cs_friend_da += 1
        $ cs_da_day3_music_talk = True
        jump cs_day3_scene_148a

    "Предложить просто посидеть рядом в тишине":
        $ cs_da_day3_shared_silence = True
        jump cs_day3_scene_148b
```

Это пример структуры. Используй реальные имена label и обнаруженный счётчик Дарьи, если он отличается.

Одно очко начисляется только за первый вариант.

Второй вариант не штрафует игрока: он открывает отдельный бытовой эпизод на четвёртый день.

| `cs_friend_dv >= 2` и `cs_dv_music_talk_day3`       | Дарья рассказывает, что Алиса оценила содержательный разговор о гитаре.           |
| `cs_se_day3_personal_talk` при достаточной дружбе   | Лена вспоминает, что Семён стал открытее в разговоре.                             |

Эти последствия не должны давать новые очки автоматически.

### 5. Новые флаги

Если эквивалентов нет, добавить:

```
default cs_da_day3_music_talk = False
default cs_da_day3_shared_silence = False
```

В дальнейшем:

- `cs_da_day3_music_talk` — Дарья сама предлагает продолжить музыкальные занятия и рассказывает Лене о своих успехах.
- `cs_da_day3_shared_silence` — Дарья сама предлагает провести спокойный вечер вместе.

Не повторять соответствующие реплики, если событие уже выполнено.

### 6. Романтическое развитие

В сцене 152 Лена целует Дарью в щёку.

Сохранить этот момент как небольшое проявление привязанности.

Он не означает, что девушки официально вступили в отношения.

Не добавлять автоматический переход к романтической ветке.

Дарья реагирует с удивлением, но положительно.

В дальнейшем персонажи могут вспомнить этот момент, однако не должны внезапно начать представляться окружающим как пара.
