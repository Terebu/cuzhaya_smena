# День 6 — исходники интеграции

`document.json` — снимок текста и структуры Google Doc «Чужая смена Переход к шестому дню», прочитанный 13 ноября 2026. ID и revisionId сохранены внутри. Облачный документ не изменялся.

`branching.md` — предоставленная автором схема развилок. Литературный текст в документе представляет один маршрут; альтернативы реализованы в генераторе.

## Пересборка

Запустить из корня проекта:

```powershell
python -X utf8 tools/build_day06.py
```

Генератор воспроизводит восемь частей дня 6, регистрацию двенадцати CG, новую сцену `cs_day05_21` и переход с прежнего финала дня 5. Опубликованная сцена `cs_day05_20` уже содержит события главы 19.4; они не повторяются. Из её окончания убрана только финальная отбивка, чтобы продолжение шло в той же комнате. Её условия доверия и состав ночных свидетелей сохранены.

Если отдельно пересобирается день 5, его генератор также восстанавливает этот переход. Для полной пересборки нового материала после исторических генераторов снова запустить `build_day06.py`.

`tools/day06_runtime.rpy.txt` — редактируемый шаблон состояния и постановки. Готовые файлы находятся в `days/day06`. Разбивка ADV использует `chunks` из `tools/global_text_paging.py`: эффекты и награды не повторяются при разделении абзаца.

## Проверки

```powershell
python -X utf8 tools/run_day06_checks.py D:/stean/release_chuzaya_smena/day06_NEW compile lint cs_d6_high_sl cs_d6_high_dv cs_d6_high_mi cs_d6_low cs_d6_medium cs_d6_threshold cs_d6_boundaries cs_d6_romance cs_d6_save_load cs_d6_pajama_save
```

Проверки работают в отдельном движке с отдельным каталогом сохранений. Тесты не устанавливаются в пользовательскую игру. Два дополнительных сценария `cs_d6_full_high` и `cs_d6_full_low` проходят от пролога до финала дня 6. Проверка старого финального сохранения требует исходной пары `00_flow.rpy`/`00_flow.rpyc` stable перед запуском `cs_d6_old_end_create`, затем актуальных файлов перед `cs_d6_old_end_load`.

## Постановка и состояние

- Единственный видимый собеседник располагается по центру через существующий `cs_frame_focus`. Высота и размер не меняются ради сидения.
- Погружение Лены в мысли оформлено отдельными авторскими переходами; обычное описание не скрывает собеседника автоматически.
- Полноэкранные CG показываются без ростовых спрайтов. Передача подарков и прощания зависят от реальных флагов.
- Снимок отношений сохраняется до первого выбора. Четыре решения используют отдельный журнал без повторного начисления.
- Семён помнит ночь на всех маршрутах. Славя, Алиса и Мику вспоминают ночь только при своём фактическом присутствии.
- Новый день сохраняет прежние очки и признания. Романтика требует обоих флагов дня 3.
- После отъезда не возвращаются уехавшие персонажи, голоса лагерной толпы и шум полной столовой.
- Шестой день использует штатный лагерный автобус. Современный маршрут 410 остаётся в пятом дне.
- У оригинальной пристани нет варианта sunset, у умывальника — night. Для этих двух промежуточных кадров используются цветовые варианты штатных фонов; сцена на пристани также получает предоставленную автором вечернюю CG.
- К концу дня сохраняются выданные адреса, рисунок, значок, медиатор, ноты, рассказ Семёна, книга, копия записей у Ольги и состояние пятого прибора. Ключ и аптечка возвращены владельцам. День 7 не добавлен.
